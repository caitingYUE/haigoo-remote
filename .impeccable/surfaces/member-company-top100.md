# Surface: Member Company Top 100

## Overview

**范围：** 既有 Haigoo 网站的局部扩展 `/trusted-companies/top-100`，包含企业导航与从榜单进入企业详情的局部衔接。此文件记录完成实现，不能替代或重写根目录 `DESIGN.md`，也不适用于小程序 Match。

**Mode：** Operate。**Build path：** code-led。用户于 2026-10-10 批准精确的目录扩展方案；沿用既有视觉世界，无 seed、无 comp round，不记录虚构的 comp approval。质感来自清楚的中文层级、真实研究条件、连续企业行与细线。用户路径是原排名 → 申请条件与证据 → 企业详情与站内岗位 → 现有官方申请流程。

**视觉权威：** `DESIGN.md` 的 2026-08-13 palette override、`src/styles/palette-cohesion.css` 与既有 `src/styles/haigoo-design-system.css`。产品约束见 `PRODUCT.md`；任务批准方案见 `docs/superpowers/specs/2026-10-10-member-company-top100-design.md`。

**方向契约：** `index.html` 的第一条 body comment：THESIS 为比较大陆申请条件并进入岗位；OWN-WORLD 为 Haigoo 橙、墨、白、平面企业行和语义控件；STORY 为原排名、证据、企业、官方申请；FIRST VIEWPORT 为紧凑 Top 100 字标、明确标题、条件筛选和首家企业；FORM 为已批准的 Jobgether 启发目录扩展。此处只落实已批准的局部形式，未创造新的全站身份。

沿用语义 CSS 变量，不引入第二套品牌色。白色企业行置于冷浅灰页面，墨色承担信息与高承诺按钮，暖橙用于字标、链接、选中和焦点。Logo 保留原色。

## Typography

继承站点 `--hg-font-sans`：`"Avenir Next", "SF Pro Display", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。本页没有独立展示字体。控件使用继承字体；数字分数和原排名采用等宽数字，Top 100 字标采用 lining 数字。

| 角色 | 实际尺度 | 用途 |
| --- | --- | --- |
| 字标数字 | 桌面 `6rem / .95`、750；手机 `2.75rem` | 左侧紧凑 Top 100 识别 |
| 主标题 | `clamp(1.85rem, 3.05vw, 2.85rem) / 1.22`、650；手机 `1.65rem / 1.35` | 中文任务标题；上限24ch |
| 简介 | `.95rem / 1.8`；手机 `.82rem / 1.85` | 研究目的；上限65ch |
| 企业名称 | `1.05rem / 1.45`、650；手机 `.94rem` | 可独立点击的企业身份 |
| 综合分 | `1.6rem`、600；手机 `1.3rem` | 一位小数与 `/ 100`，下方明确“综合关注分” |
| 行条件与正文 | 主要 `.8rem`，限制摘要 `.75rem / 1.7`；手机摘要 `.7rem` | 资格、远程、合同、已复核限制 |
| 辅助标签 | 主要 `.65–.78rem` | 研究日期、岗位统计、复核和未知提示 |

**The Title First Rule.** 页头从 h1 到简介，再到会员身份和研究日期。身份与日期不放在标题上方成为 eyebrow。

## Layout

继承 `haigoo-shell` 的居中容器：基础宽度 `min(100% - 2.5rem, 90rem)`；48rem 起为 `min(100% - 4rem, 90rem)`；90rem 起为 `min(100% - 8rem, 97.5rem)`。页顶为既有固定 Header 留出空间（桌面110px，手机96px）。

桌面页头采用 `230px + minmax(0,1fr)` 两列和3rem间距，字标右侧一条细线。简介与会员/日期属于标题所在列。概况用双边细线划分，然后搜索、三个选择框、资格切换、结果数量和口径提示，直接连接企业列表。没有前三名领奖台、分页榜单或无限滚动。

默认企业行六列：原排名、56px Logo、企业身份、申请条件、分数、行动；`42px 56px minmax(0,1.7fr) minmax(0,1.4fr) 82px 160px`，18px间距与24px/20px内边距。高度随限制摘要增长，不截断关键条件。展开证据与企业身份对齐，六维分数一行六列，详情正文为两列。

| 宽度规则 | 已实现变化 |
| --- | --- |
| ≤1100px | 企业行五列，Logo48px；行动移至第三列开始的下一行，证据左边距112px |
| ≤767px | 页头88px字标列＋标题列，17px间距；搜索独占一行，三个选择框仍横排；资格切换独占宽度，结果数量换行 |
| ≤767px 企业行 | 28px排名＋42px Logo＋企业身份＋72px分数；条件与行动从第三列起独占下一行，参考岗位摘要隐藏；限制摘要保留 |
| ≤767px 证据 | 解除桌面左缩进，六维分数改三列两行，事实与来源改单列；评分规则同样三列两行 |

截图证据为 `.impeccable/review/desktop.jpg`（1440×1000）、`tablet.jpg`（768×1024）、`mobile.jpg`（390×844）。桌面显示前两家企业，手机首屏含筛选与首行起始。手机完整限制位于首屏以下，其保留由同一行组件和移动CSS证明；首屏截图不证明行内全部内容。

## Elevation & Depth

本页以平面白色行、冷浅灰背景和1px边线组织层级，列表没有阴影。展开内容属于同一企业行。桌面导航菜单通过定位、白色表面、边框与层级浮在 Header 下；未给本扩展增加阴影词汇。

允许动效时，企业行背景以150ms ease-out变化，研究展开箭头与导航箭头以160ms ease-out转向。`prefers-reduced-motion` 为 reduce 时这些局部过渡不启用，内容及状态仍完整可用。没有进入动画、排行榜数字动画或需等待的揭示。

## Shapes

保持连续行的平直轮廓。选择框、资格按钮与岗位分页按钮为6px轻圆角，主行动8px，Logo桌面10px/手机8px；桌面菜单12px、菜单条目8px。Logo 失败按既有来源顺序重试，最后显示名称首字母，不伪造企业图标。

## Components

### 导航与入口

远程企业父按钮始终可见，展开后先“远程企业”，再“Top 100 · 会员专属”，顺序不随身份变化。目录、榜单和企业详情相关路由保持父级选中；子项用 `aria-current` 区分。桌面菜单宽234px，移动端采用静态缩进子项。

按钮点击/触屏及键盘原生 Enter/Space可展开；Tab进入子链接，Escape关闭并将焦点返回触发按钮。点击外部关闭，路径变化或选项导航后关闭；不依赖hover。目录中另有克制的榜单链接，榜单自身返回现有企业目录。

### 筛选与连续企业行

默认显示完整100家。搜索对企业、行业、研究参考岗位做NFKC规范化与大小写不敏感匹配；行业、远程制度、合同类型和大陆资格可组合。URL携带筛选与单一展开项；清除恢复全榜。结果数量用 `aria-live="polite"`。

**The Original Rank Rule.** 筛选只缩小可见集合，始终显示研究版本的原排名。当前岗位变化不会自动改名次或研究分数。

企业名与“查看企业与岗位”是独立链接，研究说明是独立展开按钮；整行不模拟一个嵌套按钮。默认行直接呈现 `applicationNote` 已复核限制，完整细节仍在展开证据中。分数、资格、远程/合同及站内岗位数保持不同信息层级。

### 证据与研究口径

六维权重固定：大陆资格与机会30、企业远程制度15、签约与支付15、时区适配15、企业基本面15、业务与异步10；合计100。页尾公开方法用百分比表示权重，企业综合分用一位小数 `/ 100`。无页面自定义权重或重排。

2026-10-10版有100家，其中49家有官方大陆远程线索，51家大陆资格待确认，77家合同/支付类型尚未明确。这些是本研究版事实，不是未来版本的固定配额。

分项为null时显示“待确认”；部分未知显示“部分信息待确认”，雇员类别的主体待核单独说明。研究说明包含大陆申请、远程方式、合同支付、工作时段、限制、待确认问题、参考岗位、人工复核日期和可打开的官方来源。英文界面保留人工研究的原中文，明确说明此口径。

**The Separate Clocks Rule.** 排名/权重/研究日期是版本化研究；“站内岗位 · N”是当前有效站内数据，可能不限大陆。参考岗位、人才池、员工评价、规模和多数成立年不能被包装为已全面实时核验的招聘事实。

### 会员权益与页面状态

所有身份可看到导航、页头、权益说明和评分方法；完整名单、Logo、分数与企业证据仅向当前有效正式会员或管理员展示。体验周不包含此权益，免费/失效账号不解锁。会员判断复用能力函数，并由服务端当前用户状态核验；会员响应为private/no-store，不将研究数据作为public静态资产或持久化到localStorage。

| 状态 | 实现表现 |
| --- | --- |
| 权限核验/榜单加载 | 中性三行骨架，`aria-busy`；不闪现真实名单 |
| 未登录 | 权益介绍，墨色“登录查看”，登录后返回当前榜单；次要权益入口 |
| 已登录无权/体验周 | 准确权益说明，“查看正式会员权益”到现有会员中心，支持刷新会员状态 |
| 401/403 | 清理数据并显示权限页，不继续保留旧账号研究内容 |
| 网络/服务加载失败 | 明确错误说明与重试，不显示为空榜单或0岗位 |
| 筛选无结果 | 简明调整提示和“查看全部100家” |
| 企业停用/不可用 | 保留原排名和研究说明，停用无效详情链接并明确不可用 |
| 岗位统计未知 | “岗位信息待更新”，不当作零岗位 |
| 无开放岗位/人才池、岗位状态待核 | 各自明确标注，不承诺当前有效职位 |

权限与错误状态依据源码/既有验收记录，三张首屏截图仅证明有效会员的可见布局。前端研究响应按账号/Token隔离，登出、切换身份与失效后不继续呈现旧研究内容；窗口恢复焦点重新核验。仅返回所需筛选/展开/滚动状态。

### 企业详情与岗位衔接

主链接以精确 `companyId` 进入既有 `/company/:id`；岗位入口定位 `#company-profile-open-roles`。返回地址与来源携带筛选，sessionStorage仅记录滚动位置。详情从榜单进入时提示逐职位核对所在地、合同与工作时段，并给返回榜单研究入口；公开企业页不附带受保护证据。

岗位按companyId查询当前有效、已批准记录，每次24条并显示总数和载入更多。错误、加载、真实零岗位与筛选空结果分别表达。可用时保留企业官方招聘入口；无站内岗位不等于企业停止招聘。继续复用岗位详情与既有官方申请，不承诺自动代投或已经申请。

### 可访问性

主要行动、清除、筛选、导航与来源链接为至少44px触达高度；权益主按钮48px。局部控件使用2px橙色 `focus-visible` 轮廓、4px偏移。输入、筛选组、名次、展开状态和来源具有语义标签；长企业名、限制和链接允许换行。Logo为空alt且容器隐藏于辅助技术，身份由企业名称表达。

## Do's and Don'ts

- **Do** 保留网站既有视觉权威，只将本页规则应用于此目录扩展。
- **Do** 在默认企业行保留已核验申请限制，展示完整文字资格与未知信息。
- **Do** 在标题及简介下方放会员身份与研究日期，保持操作和首家企业尽快出现。
- **Do** 保留版本、原排名与研究证据；将实时岗位计数单独标作站内岗位。
- **Don't** 宣称大陆无条件可申、已确认EoR、已确认正式直接雇佣，或将Full-time解释为签约证明。
- **Don't** 将未知贡献呈现为企业待遇0分，将综合关注分说成个人匹配/录用概率/薪资排名。
- **Don't** 将人工参考岗位生成假job_id、无声替换停用企业或将接口失败显示为0。
- **Don't** 用遮罩公开下载会员名单，或用会员广告、榜单领奖台替代扫描与比较任务。
