# Surface: Member Company Top 100

## Overview

**范围：** 既有 Haigoo 网站的局部扩展 `/trusted-companies/top-100`，包含企业导航、企业详情研究、会员权益与反馈的局部衔接。此文件以最新源码记录本地实现，不能替代或重写根目录 `DESIGN.md`，也不适用于小程序 Match。此版记录 2026-10-10 用户四项季度展示调整：移除内部分类汇总与对应筛选、增加季度标签、使用指定非会员标题、以现有小程序二维码承接权益入口。本轮独立 finish review 与生产发布尚未完成；末尾的历史发布只证明此前轮次。

**Mode：** Operate。**Build path：** code-led。用户于 2026-10-10 批准精确的目录扩展方案，并明确提出本轮四项修改；原有正式会员权限、研究排名、分数、权重及岗位申请链路继续有效。沿用既有视觉世界，无 seed、无 comp round，不记录虚构的 comp approval。质感来自清楚的中文层级、真实研究条件、连续企业行与细线。用户路径是原排名 → 申请条件与证据 → 企业详情与站内岗位 → 现有官方申请流程。

**视觉权威：** `DESIGN.md` 的 2026-08-13 palette override、`src/styles/palette-cohesion.css` 与既有 `src/styles/haigoo-design-system.css`。产品约束见 `PRODUCT.md`；任务批准方案见 `docs/superpowers/specs/2026-10-10-member-company-top100-design.md`。

**方向契约：** `index.html` 的第一条 body comment：THESIS 为比较大陆申请条件并进入岗位；OWN-WORLD 为 Haigoo 橙、墨、白、平面企业行和语义控件；STORY 为原排名、证据、企业、官方申请；原 FIRST VIEWPORT 写为紧凑 Top 100 字标、明确标题、资格/筛选和首家企业；当前源码已按用户要求移除资格分类筛选并加入季度工具栏，实际内容及首屏位置以源码和本轮截图为准；FORM 为已批准的 Jobgether 启发目录扩展。此处只落实已批准的局部形式，未创造新的全站身份。

## Layout

继承 `haigoo-shell` 的居中容器：基础宽度 `min(100% - 2.5rem, 90rem)`；48rem 起为 `min(100% - 4rem, 90rem)`；90rem 起为 `min(100% - 8rem, 97.5rem)`。页顶为既有固定 Header 留出空间（桌面110px，手机96px）。

桌面页头采用 `230px + minmax(0,1fr)` 两列和3rem间距，字标右侧一条细线。简介、会员身份及“了解评分规则”链接属于标题所在列。顶部工具栏左侧返回远程企业、右侧显示季度标签；可换行。旧概况汇总不再渲染，也不保留空栏。搜索、三个选择框、右对齐结果数量和口径提示直接连接企业列表，筛选区顶部细线分界。没有前三名领奖台、分页榜单或无限滚动。

默认企业行六列：原排名、56px Logo、企业身份、申请条件、分数、行动；`42px 56px minmax(0,1.7fr) minmax(0,1.4fr) 82px 160px`，18px间距与24px/20px内边距。高度随限制摘要增长，不截断关键条件。展开证据与企业身份对齐，六维分数一行六列，详情正文为两列。

## Elevation & Depth

本页以平面白色行、冷浅灰背景和1px边线组织层级，列表没有阴影。展开内容属于同一企业行。桌面导航菜单通过定位、白色表面、边框与层级浮在 Header 下；列表继续平面呈现。二维码原生模态弹窗使用局部阴影 `0 24px 70px -24px rgba(24,32,51,.4)`，背景遮罩为 `rgba(24,32,51,.46)`；这些值只记录此弹窗，不扩展全站 token。

允许动效时，企业行背景以150ms ease-out变化，研究展开箭头与导航箭头以160ms ease-out转向。`prefers-reduced-motion` 为 reduce 时这些局部过渡不启用，内容及状态仍完整可用。没有进入动画、排行榜数字动画或需等待的揭示。

## Shapes

保持连续行的平直轮廓。选择框、季度标签与岗位分页按钮为6px轻圆角，主行动8px，Logo桌面10px/手机8px；桌面菜单及二维码弹窗12px、菜单条目8px。Logo 失败按既有来源顺序重试，最后显示名称首字母，不伪造企业图标。

## Components

### 导航与入口

远程企业父按钮始终可见，展开后先“远程企业”，再“Top 100 · 会员专属”，顺序不随身份变化。目录、榜单和企业详情相关路由保持父级选中；子项用 `aria-current` 区分。桌面菜单宽234px，移动端采用静态缩进子项。

按钮点击/触屏及键盘原生 Enter/Space可展开；Tab进入子链接，Escape关闭并将焦点返回触发按钮。点击外部关闭，路径变化或选项导航后关闭；不依赖hover。头像菜单同样使用点击、键盘、外部 pointerdown 和路由变化关闭；切换查询也关闭已打开菜单。目录中另有克制的榜单链接，榜单自身返回现有企业目录。

### 筛选与连续企业行

默认显示完整100家。搜索对企业、行业、研究参考岗位做NFKC规范化与大小写不敏感匹配；行业、远程制度和合同类型可组合。内部 A/B 汇总与对应分类计数筛选已移除；旧 `tier` URL 参数不再参与筛选，但各企业具体申请条件仍保留。URL携带现有筛选与单一展开项；清除恢复全榜。结果数量用 `aria-live="polite"`。

**The Original Rank Rule.** 筛选只缩小可见集合，始终显示研究版本的原排名。当前岗位变化不会自动改名次或研究分数。

企业名与“查看企业与岗位”是独立链接，研究说明是独立展开按钮；整行不模拟一个嵌套按钮。默认行直接呈现 `applicationNote` 已复核限制，完整细节仍在展开证据中。分数、资格、远程/合同及站内岗位数保持不同信息层级。

### 证据与研究口径

六维权重固定：大陆资格与机会30、企业远程制度15、签约与支付15、时区适配15、企业基本面15、业务与异步10；合计100。页尾公开方法用百分比表示权重，企业综合分用一位小数 `/ 100`。无页面自定义权重或重排。

研究版仍有100家真实企业，具体大陆资格、合同限制、时区和待确认事实继续在企业行与证据中表达。内部分类不再作为页头汇总或独立选择入口；不记录任何未来版本的固定分类配额。

分项为null时显示“待确认”；部分未知显示“部分信息待确认”，雇员类别的主体待核单独说明。研究说明包含大陆申请、远程方式、合同支付、工作时段、限制、待确认问题、参考岗位、人工复核日期和可打开的官方来源。英文界面保留人工研究的原中文，明确说明此口径。

**The Separate Clocks Rule.** 排名/权重/研究日期是版本化研究；“站内岗位 · N”是当前有效站内数据，可能不限大陆。参考岗位、人才池、员工评价、规模和多数成立年不能被包装为已全面实时核验的招聘事实。

### 会员权益与页面状态

所有身份可看到导航、页头、权益说明和评分方法；完整名单、Logo、分数与企业证据仅向当前有效正式会员或管理员展示。体验周不包含此权益，免费/失效账号不解锁。会员判断复用能力函数；服务端使用当前数据库的权威只读会员 SELECT 核验，不用本地用户兜底，也不在读取研究时隐式写入会员到期状态。核验失败拒绝交付私有数据；会员响应为 private/no-store，不将研究数据作为 public 静态资产或持久化到 localStorage。

| 状态 | 实现表现 |
| --- | --- |
| 首次权限核验/榜单加载 | 中性三行骨架，`aria-busy`；不闪现真实名单 |
| 同账号后台核验 | 保持现有列表挂载，并提示正在核验；成功核验不重置当前位置 |
| 未登录 | 指定标题与权益介绍；墨色“登录查看”保留榜单回链，次要“了解会员权益”打开二维码 |
| 已登录无权/体验周/会员到期 | 指定标题、准确状态说明；墨色“了解会员权益”打开二维码，支持刷新会员状态 |
| 401/登录过期 | 清理数据，提示登录失效并提供“重新登录”，保留榜单回链 |
| 403/权益不足 | 清理数据，显示正式会员权益说明、二维码权益入口与刷新会员状态入口 |
| 网络/服务加载失败 | 明确错误说明与重试，不显示为空榜单或0岗位 |
| 筛选无结果 | 简明调整提示和“查看全部100家” |
| 企业停用/不可用 | 保留原排名和研究说明，停用无效详情链接并明确不可用 |
| 岗位统计未知 | “岗位信息待更新”，不当作零岗位 |
| 无开放岗位/人才池、岗位状态待核 | 各自明确标注，不承诺当前有效职位 |

权限与错误状态依据源码与隔离 fixture 验证；首屏截图仅证明该测试身份的可见布局。共享私有请求 hook 按账号、Token 与单企业范围隔离响应；登出、切换身份、JWT 过期与会员到期后清理旧研究内容。请求20秒超时并在卸载/身份变化时 abort；窗口恢复焦点、恢复可见与定时后台核验不会以骨架替换成功列表。AuthContext 完整读取 me 响应前后核对 Token；跨标签 storage 只同步状态，不让旧退出事件反写并擦除新登录。权益中心的明确返回入口携带重新核验状态，回到榜单自动调用 refreshUser；也可手动刷新会员状态。

### 季度标签与维护

当前公共 edition 为 `2026-10-10.v1`，研究日期 `2026-10-10`，季度 `2026 Q4`，下次复核 `2027-01-10`。右上角中文标签精确为“2026 Q4 统计数据，季度更新”；英文为“2026 Q4 data · Updated quarterly”。页面由已发布研究日期推导季度，访问日期跨季度不自动改变此标签；用户提到的 Q3 仅为格式示例。会员数据返回时使用其研究日期，否则使用四字段公共 edition。

私有稳定快照为 `lib/data/company-top100-current.json`；公共 `company-top100-edition.json` 当前仅含 `version`、`researchedAt`、`quarter`、`nextReviewAt` 四个字符串，不含名单和分数。服务端载入与 `prebuild` 复用同一快照/edition 校验，元数据不一致阻止继续，不以单独改标签代替完成研究。历史由 Git 保存，旧名单不新增公开归档。

季度 heartbeat `top-100` 已配置 ACTIVE，每季度首月10日09:00（Asia/Shanghai）启动复核。先复核数据，再更新版号：`scripts/update-company-top100-edition.mjs` 默认验证候选并输出 dry-run；显式 `--write` 成对暂存当前快照与公共 edition，部署仍为独立步骤。候选必须100个唯一 companyId、原排名顺序与分数贡献有效、日期和新版本有效，并且每家企业在候选季度内且不晚于版日期完成复核。未完成复核就保留旧版号与季度；完成、失败或需要用户决策时通知。维护步骤及本轮验收记录由 `docs/qa/2026-10-10-top100-quarterly-maintenance.md` 承载。

### 指定非会员标题与二维码

guest/free/trial/expired 权益区 h2 精确为“优先选择榜单内企业，成功率更高”。这是用户明确指定的文案，未提供成功率统计对照；本次不新增量化成功率或已验证提升的主张。页尾仍说明综合关注分为研究优先级，不是个人匹配分，不保证具体岗位可从大陆申请。

“了解会员权益”统一打开 `MiniProgramMembershipDialog`，复用现有 `/miniprogram_qrcode.webp`；标题“微信扫码开通会员”，正文精确“当前仅支持小程序开通会员”。不实现网页支付、会员购买模拟或真实支付验证。登录/重新登录及已登录的“刷新会员状态”入口继续存在。
