==================================================
一、此次改造的产品状态
==================================================

Haigoo Remote 当前阶段调整为：

“免费的全球远程工作公开信息网站”。

网站不再通过岗位信息进行任何直接或间接商业转化。

当前阶段：

- 所有岗位信息免费浏览；
- 所有官方申请路径免费开放；
- 不设置岗位会员墙；
- 不通过岗位引导购买会员；
- 不通过岗位引导付费咨询；
- 不通过岗位引流微信私域；
- 不进行个性化岗位匹配；
- 不进行候选人筛选；
- 不向用户推荐特定岗位；
- 不代替用户申请；
- 不接收简历并转交企业；
- 不向企业推荐候选人；
- 不提供内推；
- 不提供企业招聘联系人作为岗位服务；
- 不提供招聘成功承诺。

用户最终自行判断岗位，并跳转企业官方渠道申请。

二、先新增统一合规开关
==================================================

请首先检查当前代码结构。

增加一个全局配置，例如：

COMPLIANCE_FREE_MODE = true

或环境变量：

NEXT_PUBLIC_COMPLIANCE_FREE_MODE=true

当该模式开启时，自动关闭：

1. paid job access
2. job matching
3. personalized recommendations
4. resume-to-job matching
5. job subscription / daily recommended jobs
6. Club job benefits
7. recruiter/contact unlock
8. private WeChat group CTA
9. referral / 内推功能

11. job-related monetization CTA

不要删除原代码，只在前端入口和相关 API 调用层关闭。

JOB_MATCHING_ENABLED=false
JOB_RECOMMENDATION_ENABLED=false
JOB_PAYWALL_ENABLED=false
JOB_SUBSCRIPTION_ENABLED=false
JOB_CONTACTS_ENABLED=false

JOB_MONETIZATION_ENABLED=false

方便未来恢复。
