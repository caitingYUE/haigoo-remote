# Mini Program 1.0.35 Production Candidate

Prepared on 2026-09-12 (Asia/Shanghai). This release supersedes the uploaded
1.0.34 package because membership validation, retained-page behavior and the
company-directory sort contract changed after that upload.

## Deployment state

- Integration branch: `codex/mini-1.0.33-production-recovery`
- WeChat state: build verification in progress; not submitted or published
- Database migrations: unchanged; no migration or data repair was executed
- The uploaded 1.0.34 package must not be submitted for review

## Release scope

- Validate the authoritative membership before restoring retained Match,
  company-directory or company-detail content.
- Keep ordinary back navigation and tab returns stable; update retained data
  only after an explicit refresh or an account/entitlement scope change.
- Accept `newest` as a backwards-compatible alias of the stable latest-company
  ordering while preserving the existing `latest` and `relevance` clients.
- Keep the stable public HTTPS media pipeline and admin job-save reliability
  fixes already verified in 1.0.34.
- Default Preview deployment and payment relay configuration to the current
  clean integration branch; allow an explicit `MINI_PREVIEW_GIT_BRANCH`
  override for future release branches.

## Accepted data policy

Company rating, size and founded year may legitimately be absent. The Mini
Program and admin site must present the values recorded by the admin source
without inventing or broadly backfilling missing fields. Industry values remain
source-controlled; corrections require targeted, source-backed edits.

## Remaining manual gate

Complete real-device acceptance for guest, free, active-member, expired-member
and refunded-member accounts. Submit version 1.0.35 for WeChat review only after
those checks pass. Publishing remains a separate manual action after approval.
