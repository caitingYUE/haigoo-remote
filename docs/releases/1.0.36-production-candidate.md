## Root cause and release scope

- Removing a favorite passed an `undefined` job snapshot into the internal
  CloudRun request. The signature encoded that property as `null`, while JSON
  transport omitted it, so the production Gateway rejected the write with 401.
- The Mini Program treated that internal 401 as an expired user session and
  cleared the login. The page then skipped its busy-state cleanup because the
  account scope had changed.
- CloudRun now signs the exact normalized JSON body it sends. Internal Gateway
  credential failures are surfaced as 502 service failures rather than user
  authentication failures.
- The client retains the session for an identified internal Gateway credential
  error, and the saved-jobs page always settles its local removal state.
- A successful removal updates the list immediately and refreshes pagination in
  the background instead of keeping the action button busy during the reload.
