# 小程序上线测试清单

## 身份矩阵

- [ ] 未登录访客可以浏览，不能收藏或申请。
- [ ] 微信已登录但未绑定账号时，收藏/申请会引导绑定。
- [ ] 已绑定免费用户可以同步收藏和申请入口记录。
- [ ] 未验证邮箱用户能收到明确提示。
- [ ] 有效会员无订阅时能创建订阅并同步网站与邮箱。
- [ ] 有效会员已有网站订阅时能直接看到订阅与岗位更新。
- [ ] 过期会员回到 Club 权益展示，不再访问会员订阅能力。

## 岗位与同步

- [ ] 列表加载第 2、3 页，不停在 20 条。
- [ ] 默认排序与网站一致，最新排序按时间倒序。
- [ ] 七个分类组合分页无重复、无跳页。
- [ ] 未登录访客仅能查看“全部”分类前 20 个岗位，搜索和其他分类均引导登录。
- [ ] 已绑定免费用户仅在首次进入岗位详情时消耗 1 次额度；列表、搜索和刷新不扣减，同一岗位不重复计数。
- [ ] 免费用户累计最多查看 100 个唯一岗位，Club 权益有效期间不受该额度限制。
- [ ] 收藏在小程序和网站双向新增/取消且重复请求无副作用。
- [ ] 申请入口复制后显示“已打开入口”，用户确认后显示“已申请”。
- [ ] 官网和邮箱申请可同时存在，且只展示真实上游数据中存在的申请入口。
- [ ] 邮箱直申弹窗完整展示收件人、主题和正文，确认后再复制。
- [ ] 小程序不展示网站当前不支持的内推入口或任何模拟申请方式。
- [ ] 最近 3 天岗位在首页、列表和详情展示 `New`，热门与 Club 标签可同时存在。
- [ ] 企业信息 Tab 正常展示，缺失字段使用空状态且不显示假数据。
- [ ] 订阅保存后网站、小程序和邮件任务使用同一订阅记录。
- [ ] 会员订阅方向可按大类切换或模糊搜索真实岗位分类，显示已选数量且最多 8 个；岗位更新仅展示最近一次成功邮件中的相同岗位且不超过 5 个。
- [ ] 首页 Hero、真实用户头像、顾问二维码和交流群二维码在体验版及真机正常加载。
- [ ] 详情收藏成功后紫底白色收藏态清晰可见，刷新后状态仍与网站一致。
- [ ] 未登录和会员用户的 Club 页面均可打开顾问/交流群二维码，会员页面优先展示订阅信息。

## 账号、安全与异常

- [ ] 注册必须勾选协议，数据库存在协议版本与时间。
- [ ] 连续错误绑定第 6 次返回 429；注册/重置第 4 次返回 429。
- [ ] 找回密码不泄露邮箱是否存在。
- [ ] 退出只清除本机状态；解绑保留网站账号；注销删除账号并设置 30 天锁。
- [ ] 弱网、超时、CloudRun/Vercel 故障有可理解提示且不会重复扣次数。
- [ ] iOS、Android、字体放大、全面屏安全区、长标题、空列表和 Logo 失败均通过。
- [ ] 新版本下载完成后出现重启更新提示。
