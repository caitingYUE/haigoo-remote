# 招聘列表更新检查复核 · 2026-10-02

范围：对照已确认的 2026-10-01 方案，复核列表检查、人工处理提醒、并发与重复操作。保留手动检查、人工录入与状态维护的边界，不恢复预检、正文采集或自动发布。

## 发现并修复

1. **旧人工确认可能屏蔽新的失效事件。** 原失效提醒仅以岗位记录 ID 标识；人工替换申请链接后仍可能命中旧的确认记录。现在使用岗位 ID 与来源身份共同标识，兼容迁移旧提醒及其人工确认。
2. **岗位身份可能碰撞。** 通用网址的 `ref` / `source` 可能是岗位标识，不再按跟踪参数删除；Workable 短码保留大小写；Lever 欧洲和其他地区的来源身份与可比范围分开。
3. **列表地区误判和漏识别。** HTML 卡片中的岗位标题不再进入地区字段，避免把 Global Accounts Manager + Remote USA 当成全球远程。支持列表 JSON-LD PostalAddress 的城市、地区和国家字段，仍不读取岗位详情或描述。
4. **人工维护后的旧标签滞留。** 岗位新增、编辑和删除成功后重新读取提醒；失败的辅助读取单独提示，不把已成功保存的岗位报为保存失败。
5. **重复请求和进度覆盖。** 每家公司完成后只读取该企业状态；直接合并该企业的 step 返回值，不重复读取全批次进度和全页状态。批次返回精简摘要，避免反复传输全部候选岗位。较晚返回的分页请求不会覆盖当前页状态；关闭检查后，已发出的检查完成时通知列表刷新。
6. **跳过检查的证据不一致。** 跳过时保留上次实际读取页数、岗位数和检查时间，不再显示读取了岗位却为零页。
