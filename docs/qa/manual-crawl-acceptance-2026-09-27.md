# 手动爬虫工作流验收（2026-09-27）

> 此为上一版记录；2026-09-28 已发布真实失败修复，当前状态以 [修复验收报告](manual-crawl-recovery-2026-09-28.md) 为准。

## 需求落实

- 当前页范围锁定；入口为「爬虫预检」「更新检查」。旧批量同步、爬虫入口和自动检查/发布/下线定时任务停用。
- 预检展示实际响应与字段样本；机器提取成功不等于人工通过。空结果、字段缺失、来源归属不明不能通过。
- 每家企业首次尝试加最多 5 次人工重试。拒绝后标记不可爬虫，企业行可重新预检。招聘链接变化使原资格失效。
- 更新仅处理人工批准的企业；逐页抓取、逐条验证已有发布岗位。新增/变更可编辑，保存待审核、发布或取消。
- 新增待审核写入企业的真实岗位；已有岗位修改草稿保留线上原版本。失效岗位须人工降为待审核或可恢复删除。
- 停止阻断后续请求和在途结果；重复提交、并发修改、跨企业操作和过期失效证据有服务端校验。
- 企业岗位结果和处理记录每页 25 条，完整字段及原文按单条读取，避免批量响应重复原文超过接口大小限制。
- 前台同步失败保留已保存岗位，并持久展示手动重试入口；旧译文对应源字段变化时清除。
